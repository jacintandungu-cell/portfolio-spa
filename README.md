# Portfolio SPA

A single-page portfolio application built with **React**.  
This project showcases creative agency projects with search functionality and dynamic project management.

---

## 🚀 Features
- Responsive landing page
- Dynamic project showcase
- Search filter for projects
- Add new projects via form
- Modern React setup with hooks

---

## 🛠️ Tech Stack
- React 18
- CSS (custom styling)
- Node.js / npm

bash

3. Run locally
